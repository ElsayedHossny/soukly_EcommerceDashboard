# 🛍️ Soukly — Modern E-Commerce Platform

**Soukly** is a modern, responsive, and multilingual e-commerce platform built with **Next.js, TypeScript, and Tailwind CSS**.

The project is designed to provide a smooth shopping experience for users in both **Arabic and English**, with full **RTL/LTR support**, authentication, product browsing, cart and wishlist management, and a responsive modern UI.

## 🔐 Authentication Flow

Soukly uses **NextAuth.js** to handle authentication and user sessions.

The authentication flow includes:

```text
User
 ↓
Register / Login
 ↓
Authentication
 ↓
Session Creation
 ↓
Authenticated User
 ↓
Access User Features
```

Authenticated users can access features such as:

* Cart
* Wishlist
* Account-related functionality

## 🌐 Internationalization

One of the main goals of Soukly is to provide a smooth experience for both Arabic and English users.

The application supports:

```text
English → LTR
Arabic  → RTL
```

The layout automatically adapts based on the selected language.

This includes:

* Navigation
* Text direction
* UI layout
* Product-related content
* Buttons and forms
